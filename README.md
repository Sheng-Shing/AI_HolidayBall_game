# AI Holiday Ball Game

勝行科技智慧團康 AI 的彩色球接球遊戲原型。玩家需要移動底部三色擋板，接住從上方落下的紅、綠、藍色球，讓球落在相同顏色的區段即可得分。

此專案是純前端實作，不需要安裝套件或建置流程，可直接用瀏覽器開啟。

## 遊戲玩法

- 紅、綠、藍三種球會從畫面上方隨機落下。
- 底部擋板分成紅、綠、藍三個區段。
- 球落到相同顏色的擋板區段時加分。
- 球落錯顏色或沒有接到會扣生命。
- 分數達到門檻後會升級，球速、生成頻率和同時出現的球數會逐步增加。

## 操作方式

### 鍵盤

- `←`：向左移動擋板
- `→`：向右移動擋板

### 好樂球 BLE 控制器

遊戲支援透過 Web Bluetooth 連接好樂球控制器。

1. 使用支援 Web Bluetooth 的瀏覽器開啟遊戲。
2. 點選「連接好樂球」。
3. 畫面顯示「請勿握壓軟球」時，請保持軟球未受壓，讓裝置完成校正。
4. 收到裝置初始化回應後，狀態會變成「已連接」。
5. 連接後可透過握壓左右軟球控制擋板移動。

BLE 壓力值會先扣除校正基準值，再正規化為 0 到 1 的控制值。

## 執行方式

直接用瀏覽器開啟：

```text
index.html
```

或在專案資料夾啟動任意靜態伺服器後開啟頁面。

> Web Bluetooth 通常需要在 HTTPS 或 localhost 環境下使用。若直接開啟檔案時無法連接 BLE，請改用本機伺服器。

## 主要功能

- 彩色球隨機生成與下落
- 三色擋板碰撞判定
- 分數、生命、關卡系統
- 難度遞增機制
- 遊戲結束與重新開始
- Web Bluetooth 好樂球控制器整合
- BLE 初始化與左右壓力校正

## 技術

- HTML
- CSS
- JavaScript
- Web Bluetooth API

## 注意事項

- iOS 裝置的 Web Bluetooth 支援度有限，實際可用性會依瀏覽器而不同。
- 若瀏覽器不支援 Web Bluetooth，仍可使用鍵盤操作遊戲。
- 好樂球連線校正期間請勿握壓軟球，以避免壓力基準值偏移。
